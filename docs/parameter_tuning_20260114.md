## 3. 理論計算

### 3.1 使用した理論

**リトルの法則 (Little's Law, 1961)**

```
L = λ × W
```

- L: システム内平均顧客数
- λ: 到着率
- W: 平均滞在時間

### 3.2 計算手順

#### Step 1: 平均飛行時間

```
W = 平均経路距離 / 平均速度
  = 6,978.4 m / 12 m/s
  = 581.5 秒 (9.7分)
```

#### Step 2: 必要なシステム内UAV数

```
負荷率 ρ = L / C （C: 総リンク容量）

L = ρ × C
  = 0.5 × 1,514
  = 757 機
```

#### Step 3: 必要な到着率

```
λ = L / W
  = 757 / 581.5
  = 1.3017 機/秒
```

#### Step 4: 平均発生間隔

```
T = n / λ （n: 1回あたりの生成数）
  = 10 / 1.3017
  = 7.68 秒
```

## 4. 定常状態到達時間の推定

### 4.1 使用したモデル

**M/G/∞待ち行列モデル**

システム内顧客数N(t)の期待値:

```
E[N(t)] = L × (1 - e^(-t/W))
```

- L: 定常状態のUAV数 = 757機
- W: 平均飛行時間 = 581.5秒（時定数τ）

### 4.2 到達時間の計算

| 到達レベル | 計算式 | 時間 |
|-----------|--------|------|
| 63%（1τ） | t = W | 9.7分 |
| 90% | t = -W × ln(0.1) | 22.3分 |
| **95%** | t = -W × ln(0.05) | **29.0分** |
| 99% | t = -W × ln(0.01) | 44.6分 |

### 4.3 推奨ウォームアップ時間

**30分**（定常状態の95%以上に到達）

## 7. 注意事項

- これは理論値であり、実際のシミュレーションでは以下の要因により調整が必要になる可能性がある:
  - 経路探索アルゴリズムによる負荷の偏り
  - 待機時間の発生による滞在時間の増加
  - ネットワーク構造による局所的な混雑

- 定常状態の判定は「観測」によって行い、理論値からの乖離を確認する

- ウォームアップ時間30分は95%到達の目安であり、より厳密な定常状態が必要な場合は45分（99%到達）を推奨

## 9. 各数値の詳細な導出過程

### 9.1 平均飛行時間（9.7分 = 581.5秒）

**導出方法**: ダイクストラ法による全点対最短経路計算

```
Step 1: トポロジーからグラフを構築
  - 221ノード、600リンク（無向グラフとして扱う）

Step 2: サンプリングによる平均経路長計算
  - 100ノードをランダム選択
  - 各ノードから全ノードへの最短経路を計算
  - 22,000ペアの経路距離を平均

Step 3: 結果
  平均経路距離 = 6,978.4 m

Step 4: 平均飛行時間の計算
  UAV速度 = 8〜16 m/s（コードより: speed = 8 + random * 8）
  平均速度 = (8 + 16) / 2 = 12 m/s

  平均飛行時間 W = 平均経路距離 / 平均速度
                = 6,978.4 m / 12 m/s
                = 581.5 秒
                = 9.69 分 ≒ 9.7分
```

### 9.2 予想システム内UAV数（757機）

**導出方法**: 負荷率の定義から逆算

```
Step 1: 総リンク容量の計算
  トポロジーファイルから:
  - 容量2のリンク: 443本 → 443 × 2 = 886
  - 容量4のリンク: 157本 → 157 × 4 = 628
  - 総リンク容量 C = 886 + 628 = 1,514

Step 2: 負荷率の定義
  負荷率 ρ = システム内UAV数 L / 総リンク容量 C

Step 3: 目標負荷率から必要UAV数を計算
  目標 ρ = 50% = 0.5

  L = ρ × C
    = 0.5 × 1,514
    = 757 機
```

### 9.3 平均発生間隔（7.7秒）

**導出方法**: リトルの法則から逆算

```
Step 1: リトルの法則
  L = λ × W
  ここで:
    L = システム内平均UAV数 = 757機
    W = 平均滞在時間 = 581.5秒
    λ = 到着率（機/秒）

Step 2: 到着率を求める
  λ = L / W
    = 757 / 581.5
    = 1.3017 機/秒

Step 3: 平均発生間隔を計算
  1回の生成で10機のUAVを発射するため:

  到着率 λ = UAV生成数 n / 平均発生間隔 T

  T = n / λ
    = 10 / 1.3017
    = 7.68 秒 ≒ 7.7秒
```

### 9.4 定常状態到達時間（30分）

**導出方法**: M/G/∞待ち行列モデルによる過渡解析

```
Step 1: M/G/∞モデルの過渡解
  E[N(t)] = L × (1 - e^(-t/W))

Step 2: 95%到達時間を計算
  0.95 = 1 - e^(-t/W)
  e^(-t/W) = 0.05
  -t/W = ln(0.05)
  t = -W × ln(0.05)
    = -581.5 × (-2.996)
    = 1742 秒
    = 29.0 分 ≒ 30分
```
