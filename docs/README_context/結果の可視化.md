# 結果の可視化

最終更新: 2026-08-03

---

## 前提

- シミュレーション実行済みで `src/result/sim_N/large_scale/[METHOD]/` に結果が存在すること
- Python仮想環境が未セットアップの場合は先に実行:
  ```bash
  make venv-setup
  ```

---

## 基本的なワークフロー

多くのグラフ生成コマンドは `SIM_ID` と `METHOD` の指定が必要.

```
SIM_ID  : シミュレーションID（make run SIM_ID=N で実行した N）
METHOD  : 経路探索手法名（Bisectional / PS / EPS / PGEPS / Dijkstra）
          ※省略時は Bisectional
```

---

## 1. リンク別CSVの抽出（前処理）

`link_status.csv`（全リンク・全時刻を含む大きなファイル）をリンク別に分割する.
`plot-link`, `plot-top-load`, `plot-load-ranking` の前に一度だけ実行が必要.

```bash
make extract-links SIM_ID=N [METHOD=X]
```

- 入力: `src/result/sim_N/large_scale/[METHOD]/link_status/link_status.csv`
- 出力: `src/result/sim_N/large_scale/[METHOD]/link_status/links/link_{from}_{to}.csv`
- 出力: `src/result/sim_N/large_scale/[METHOD]/link_status/links/_summary.csv`（全リンク最大負荷率集計）

---

## 2. グラフ生成コマンド一覧

### 混雑率グラフ

時刻別の混雑率（輻輳しているリンクの割合）の推移グラフ.

```bash
make plot-congestion SIM_ID=N [METHOD=X] [Y_MAX=N] [Y_INTERVAL=N]
```

- 入力: `src/result/sim_N/large_scale/[METHOD]/link_status/congestion_rate.csv`
- 出力: `output/sim_N/graphs/congestion_rate.png`

```bash
# 例: SIM_ID=1, Bisectional（デフォルト）
make plot-congestion SIM_ID=1

# Y軸最大値を100%, 間隔を20%に指定
make plot-congestion SIM_ID=1 Y_MAX=100 Y_INTERVAL=20
```

---

### ヒートマップ

ネットワークトポロジ上に各リンクの負荷率を色で表すスナップショット画像.

**全スナップショット一括生成:**

```bash
make heatmap-all SIM_ID=N [METHOD=X]
```

- 入力: `src/result/sim_N/large_scale/[METHOD]/snapshot/`
- 出力: `output/sim_N/heatmap/[METHOD]/snapshot_*.png`（スナップショット枚数分）

```bash
# 例
make heatmap-all SIM_ID=1 METHOD=Bisectional
```

**単一スナップショット:**

```bash
make heatmap SNAPSHOT=src/result/sim_N/large_scale/[METHOD]/snapshot/snapshot_XXX.csv
```

---

### ヒートマップ動画

ヒートマップ画像を時系列に並べた動画（MP4）を生成する. 事前に `heatmap-all` が必要.

```bash
make heatmap-video SIM_ID=N [METHOD=X] [FPS=2]
```

- 出力: `output/sim_N/videos/heatmap_[METHOD].mp4`

---

### リンク別負荷率グラフ

特定リンクの時系列負荷率グラフ. 事前に `extract-links` が必要.

```bash
make plot-link SIM_ID=N [METHOD=X] FROM=X TO=Y
```

- 入力: `src/result/sim_N/large_scale/[METHOD]/link_status/links/`
- 出力: `output/sim_N/graphs/link_load_{FROM}_{TO}.png`

```bash
# 例: ノード117→123のリンク
make plot-link SIM_ID=1 METHOD=PS FROM=117 TO=123
```

---

### 最大負荷率 Top N グラフ

全リンクの最大負荷率を降順に並べた棒グラフ. 事前に `extract-links` が必要.

```bash
make plot-top-load SIM_ID=N [METHOD=X] [TOP_N=10]
```

- 入力: `src/result/sim_N/large_scale/[METHOD]/link_status/links/_summary.csv`
- 出力: `output/sim_N/graphs/top{TOP_N}_max_load_links.png`

```bash
# Top20にする場合
make plot-top-load SIM_ID=1 METHOD=PS TOP_N=20
```

---

### 全リンク負荷率ランキング

全リンクを最大負荷率で降順にソートしたバーグラフ. 事前に `extract-links` が必要.

```bash
make plot-load-ranking SIM_ID=N [METHOD=X] [Y_MAX=N] [Y_INTERVAL=N]
```

- 出力: `output/sim_N/graphs/load_ranking.png`

---

### トポロジ描画

ネットワークトポロジのグラフ構造を描画する.

```bash
# ノード番号なし
make plot-topology

# ノード番号あり
make plot-topology-labels
```

- 出力: `output/sim_N/topology_koriyama_topology.png`

## 3. 複数シミュレーション比較グラフ

複数の SIM_ID / 手法の結果を比較するグラフを生成する. いずれも**対話形式**で入力する.

### 手法比較グラフ（積み上げ棒グラフ）

```bash
make plot-method-comparison
# または日本語ラベル版:
make plot-method-comparison-jp
```

- データソース: `src/result/sim_X/large_scale/{手法名}/time/ave_flightStatus.csv`
- ※事前に `make aggregate-flight-to SIM_ID=N METHOD=X` が必要

---

### CDF比較グラフ群

複数手法・複数 SIM_ID のCDF（累積分布関数）を重ね書きして比較する.

| コマンド | 比較対象 |
|---|---|
| `make plot-flight-cdf-comparison` | 総飛行時間（flightTime） |
| `make plot-real-flight-cdf-comparison` | 実飛行時間（realFlightTime） |
| `make plot-preflight-wait-cdf-comparison` | 飛行前待機時間（pathWaitTime + flightStayingTime） |
| `make plot-inflight-wait-cdf-comparison` | 飛行中待機時間（waitingTime） |
| `make plot-distance-cdf-comparison` | 飛行距離（distance） |

- データソース: `src/result/sim_X/large_scale/{手法名}/time/client*/flight_times.csv`

---

### 容量超過率比較グラフ

各手法の容量超過率（`flightStayingTime > 0` のUAVが存在するクライアントの割合）を比較する.

```bash
# 容量超過率を事前に算出（手法・SIM_IDごとに実行）
make analyze-exceeded SIM_ID=N [METHOD=X]

# 比較グラフ生成（対話形式）
make plot-exceeded-rate-comparison
make plot-exceeded-rate-comparison-jp  # 日本語ラベル版
```

- データソース: `src/result/sim_X/large_scale/{手法名}/capacity_exceeded.csv`

---

## 4. 飛行ステータス集計

個別クライアントの飛行時間データを手法ごとに平均集計する.

```bash
make aggregate-flight-to SIM_ID=N [METHOD=X] [OUTPUT_SIM=M]
```

- 入力: `src/result/sim_N/large_scale/[METHOD]/time/`
- 出力: `src/result/sim_M/time/ave_flightStatus.csv`

```bash
# 例: SIM_ID=1 の PS 結果を集計
make aggregate-flight-to SIM_ID=1 METHOD=PS OUTPUT_SIM=1
```

---

## 5. 出力ファイル一覧

```
output/sim_N/
├── graphs/
│   ├── congestion_rate.png              # 混雑率グラフ
│   ├── link_load_{from}_{to}.png        # リンク別負荷率グラフ
│   ├── top{N}_max_load_links.png        # 最大負荷Top Nグラフ
│   ├── load_ranking.png                 # 全リンク負荷率ランキング
│   └── flight_time_cdf.png             # 飛行時間CDFグラフ
├── heatmap/
│   └── [METHOD]/
│       └── snapshot_*.png              # 時刻別ヒートマップ
└── videos/
    └── heatmap_[METHOD].mp4            # ヒートマップ動画
```

比較グラフ（複数手法）は `output/` 直下に出力される:
```
output/
├── method_comparison.png
├── flight_time_cdf_comparison.png
├── exceeded_rate_comparison.png
└── ...
```
