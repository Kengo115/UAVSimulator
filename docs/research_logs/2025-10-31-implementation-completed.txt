3. アルゴリズムの動作フロー
================================================================================

【基本フロー】
1. currentFlow = requestedFlow で開始
   例: 要求フロー32でスタート

2. EPS計算を1イテレーション実行

3. 予防型不安定性スコアを計算

4. 判定と処理:
   [A] スコア >= 5.0 (緊急)
       → 2UAV減少
       → consecutiveStableForIncrease = 0
       → ステップ2へ

   [B] スコア >= 3.0 (警告)
       → 1UAV減少
       → consecutiveStableForIncrease = 0
       → ステップ2へ

   [C] スコア < 3.0 (安定)
       → stableIterationCount++
       → consecutiveStableForIncrease++
       → ステップ5へ

5. フロー増加判定（consecutiveStableForIncrease >= 50の場合）:
   [A] 残りギャップ > 5UAV:
       - スコア < 0.5: 5UAV増加（または残りの50%）
       - スコア < 1.5: 3UAV増加（または残りの30%）
       - スコア >= 1.5: 2UAV増加

   [B] 残りギャップ <= 5UAV:
       - スコア < 1.0: 1UAV増加（慎重）
       - スコア >= 1.0: 増加しない（安定優先）

   [C] フロー増加成功:
       → stableIterationCount = 0
       → consecutiveStableForIncrease = 0
       → ステップ2へ

6. 収束判定:
   stableIterationCount >= 500 → 収束完了
