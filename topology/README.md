# ネットワークトポロジファイルの使用方法

## 概要

UAVシミュレーターでは、ネットワークトポロジを外部ファイルから読み込むことができます。
これにより、異なるネットワーク構成を簡単にテストできます。

## ファイルフォーマット

トポロジファイルはテキスト形式で、以下の要素を含みます：

### 1. コメント
`#`で始まる行はコメントとして扱われます。

### 2. ノード数の定義
```
NODES <ノード数>
```
例: `NODES 6`

### 3. ノードの座標定義
```
NODE <ID> <X座標> <Y座標>
```
- ID: 0から始まる連続した整数
- X, Y: 0.0～1.0の範囲の正規化座標

例: `NODE 0 0.1 0.4`

### 4. リンクの定義
```
LINK <始点ID> <終点ID> <容量> <距離> <チューブ長さ>
```
- 始点ID, 終点ID: ノードのID
- 容量: 同時に飛行可能なUAV数
- 距離: 実際の距離（メートル）
- チューブ長さ: PhysarumSolverアルゴリズム用の相対長

例: `LINK 0 1 5 250 1.0`

**注意**: リンクは双方向なので、片方向のみ定義すれば自動的に両方向が設定されます。

## サンプルファイル

`default_topology.txt`に現在のデフォルトトポロジと同等の設定例があります。

## 使用方法

### コマンドライン引数で指定（将来実装予定）
```bash
java controller.BoundaryController topology/my_topology.txt
```

### CUIで対話的に指定（現在の方法）
プログラム起動時に以下のように入力を求められます：

```
=== UAVシミュレーター ===
ネットワークトポロジファイルのパスを入力してください:
（Enterキーのみを押すとデフォルトトポロジを使用します）
> topology/default_topology.txt
```

- トポロジファイルのパスを入力: 指定したファイルからトポロジを読み込みます
- Enterキーのみ: デフォルトのハードコードされたトポロジを使用します

## 相対パスと絶対パス

### 相対パスの場合
プロジェクトのルートディレクトリ（UAVSimulator/）からの相対パスで指定します：
```
topology/default_topology.txt
topology/custom_network.txt
```

### 絶対パスの場合
ファイルシステムの絶対パスで指定できます：
```
/Users/username/Documents/my_topology.txt
/home/user/networks/test_topology.txt
```

## トポロジファイルの作成例

6ノードの線形ネットワーク：
```
# Linear Network Topology
NODES 6

NODE 0 0.1 0.5
NODE 1 0.3 0.5
NODE 2 0.5 0.5
NODE 3 0.7 0.5
NODE 4 0.9 0.5
NODE 5 1.0 0.5

LINK 0 1 10 200 1.0
LINK 1 2 10 200 1.0
LINK 2 3 10 200 1.0
LINK 3 4 10 200 1.0
LINK 4 5 10 200 1.0
```

## エラーハンドリング

ファイル読み込み時に以下のエラーがチェックされます：

- ファイルが存在しない
- フォーマットエラー（不正な行）
- ノード数の不一致
- 座標が範囲外（0.0～1.0）
- ノードIDの欠落または重複
- リンクが存在しないノードを参照
- 自己ループ（同じノードへのリンク）

エラーが発生した場合、詳細なエラーメッセージが表示されます。

## デフォルトトポロジ

デフォルトトポロジは以下の6ノード構成です：

```
     ①-------④
     |       |
     ⓪---③   |
     |   |   |
     |   ②---⑤
```

- ノード数: 6
- リンク数: 8（双方向で16方向）
- 容量: 5～15 UAV
- 距離: 250～850m

詳細は`default_topology.txt`を参照してください。

## トラブルシューティング

### ファイルが見つからない
- 相対パスは実行ディレクトリからの相対位置です
- 絶対パスを使用することを推奨

### 座標エラー
- 座標は必ず0.0～1.0の範囲にしてください
- 小数点は`.`を使用してください

### コンパイルエラー
- プロジェクトを再コンパイルしてください
- 必要なクラスが全て含まれているか確認してください
